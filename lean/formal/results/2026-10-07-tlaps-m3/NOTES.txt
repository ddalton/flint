M3 -- Inv_ShortcutSound and Inv_ReaderSound in TLAPS, 2026-10-07.

THE INVARIANT.  IndM3 = IndM2 /\ M3, M3 = six conjuncts (MCLeanP1M3.tla states
them over LeanP1.tla for TLC; gen-proof.py states them in the proof):

  M3Seq       seq >= 1.  Init sets seq = 1 and seq never falls, so a record of
              0 ("nothing derived": a consume or sync that left a path, a
              rescope's second half) never matches the pointer.
  Bounds      derived <= seq, memo <= seq, rnow <= seq, and derived # 0 =>
              memo <= derived -- for every tree (the plan's I9 and I10; a
              non-reader's memo is 0).  `memo` is written only by RPullSync,
              as `rnow`, and RPullSync writes `derived` = seq >= rnow or 0.
  Record      the plan's I8: derived = seq /\ sStage = "none" =>
              every held path where doc # baseline is in `skipped`.
  CasedMine   pc = "cased" => every path of uploads \cap upDone has
              inst = snap (Install puts the snapshot there, and takes `gone`
              out of upDone).
  CasedAdv    pc = "cased" /\ adv => every held path outside the install's
              own (uploads \cap upDone, deletes) where inst # baseline is
              skipped.  Install sets adv only when derived = seq
              (CommitAdvanceGuarded), so Record held over the document it
              replaced, and the install keeps that document at every such
              path (InstallInst: `gone` keeps doc[p], a foreign path keeps
              doc[p]).
  CasedSame   pc = "cased" /\ derived = seq => adv /\ inst = doc: a record
              still current after the CAS means the CAS moved nothing.

WHY FINISH NEEDS THE THREE CASED FACTS.  Finish sets derived := seq when
adv /\ inst = doc, moves the baseline to the snapshot on the install's own
paths and to Nil on its deletes, and takes those paths out of `skipped`.
For Record afterwards: on its own paths the baseline is snap = inst = doc
(CasedMine); on a delete, inst = Nil (M1's Cased) = the new baseline = doc;
everywhere else the baseline is unchanged, doc = inst, and CasedAdv says the
path is skipped.  When the finish does not advance, CasedSame says the
record was not current, so Record is vacuous.

WHY NOTHING ELSE NEEDS MORE.  Record reads doc, seq and five tree fields
(derived, sStage, baseline, scope, skipped); never `local`.  The agent's
edits only touch `local`, and the cheap path re-checks the skipped paths
against `local` (RecheckSkipped) -- that is where an edit back to the
baseline is caught.  Every step that moves the document moves seq
(SeqEv: seq' = seq => doc' = doc; GCas without its CAS and Install
with nothing to install move neither), so a record current after a step was
current before it with the same document.  The consume and the two syncs
record derived = seq only when nothing was left (ConsumeKeepsLeft,
SyncKeepsLeft); then a path they did not take was not owed, and a held,
moved, un-owed path is dirty (ConsumeHonorsScope: an owed path is held), so
it is in the new `skipped`.  A checkout's baseline is the document on its
scope and Nil off it.  A rescope's halves set sStage (the first) and
derived = 0 (the second).

THE CLAIMS.  Inv_ShortcutSound: an idle, rescope-free writer on the cheap
path has derived = seq and every skipped path dirty (RecheckSkipped); an
owed path is held, moved and clean (ConsumeHonorsScope); Record puts it in
`skipped`; contradiction.  Inv_ReaderSound: a reader that skips has memo =
seq and (ReaderRechecksOwed) derived # 0 and every skipped path dirty;
Bounds gives seq = memo <= derived <= seq; then as above.  Both are lemmas
off the invariant (ShortcutFromRecord, ReaderFromRecord), not conjuncts, so
the two rules they use are controls at those lemmas.

THE PROOF'S SHAPE.  One generic lemma, M3Write: from M3, the step's SeqEv
and its written tree R (Wr(t, R); t = "none" for the gateway and the
no-tree steps), five facts about R -- RB (bounds), RRec (record), RMine,
RAdv, RSame -- give M3'.  Every step lemma restates the step, reads R's
fields in two batches of seven, and proves the five facts; most are one
line (a field kept, or pc not "cased").  The real cases: Consume's second
tree, Sync, RPullSync (RRec: nothing left, and a path not taken was not
owed); Install (RRec, RAdv, RSame: the only writer step that moves the
document); Finish (RRec by the three cased facts); Checkout (RRec by
CheckoutHeld); RescopeSecond (RRec: derived = 0 # seq).
