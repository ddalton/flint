# Phase D: the ~180 apiserver req/s that did not scale with shares (box, 2026-10-02)
#
# Cause: a self-triggering reconcile loop on every LIVE share. A live share is
# never apply-gated, and each apply stamped chert.us/render-verified-at = now
# on its Deployment. The stamp changed every second, so every apply was a real
# change; the operator's .owns(Deployment) watch then triggered the next
# reconcile. An annotation change also bumps a Deployment's generation, so
# kube-controller-manager re-synced it and its ReplicaSets and wrote status,
# a second trigger. Parked shares skip their applies and never looped; live
# shares looped as fast as the operator could reconcile, so the total sat near
# its throughput (~15 reconciles/s) at 20 live or 150.
