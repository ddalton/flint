Consistency — hub vs direct, side by side

one page · NFS over S3 vs FUSE over S3

The intuition — "FUSE talks straight to S3, so it should be more consistent" — is reasonable, and it inverts. Consistency is not proximity to the store; it is arbitration. The hub is the arbiter, and removing it is what direct mode trades away. This page asks both modes the same eight questions.
