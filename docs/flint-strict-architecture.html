Strict mode — fsync becomes an S3 PUT

1 / 2 · durability

A per-share, per-path upgrade to the hub: an acked fsync is durable in regional S3 — a stronger guarantee than EFS's replication — bought with a group-committed journal beside the unchanged browsable checkpoints. The UI, the bucket format, and write-back paths are untouched; only flagged paths pay the latency.

The rebuildable hub — the PVC demotes to a cache

2 / 2 · availability

Once the journal exists, S3 is the authoritative log and the hub can be rebuilt anywhere from the bucket alone: checkpoint + journal replay + protocol grace. The force-detach wait and the AZ pinning hang off the hub's PVC being load-bearing — and stop existing when it isn't. (The F29 staging wedge is consumer-side CSI state; that row stays.)
